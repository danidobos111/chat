⚠️ Firebase beállítás szükséges

A chat Firebase Realtime Database-t használ az üzenetek tárolásához. Ez ingyenes és 5 perc alatt kész.

1. Menj ide: console.firebase.google.com
2. Hozz létre egy projektet (pl. "titkos-chat")
3. Add hozzá a Realtime Database-t (Test mode)
4. Menj a projektbeállításokhoz → General → Web app → Config
5. Cseréld le a lenti részt az index.html-ben:

const firebaseConfig = { apiKey: "AIzaSyB-4SBrAVNVhyGiw48XsPozc4_fHogK7QM", authDomain: "titkos-chat.firebaseapp.com", databaseURL: "https://titkos-chat-default-rtdb.europe-west1.firebasedatabase.app", projectId: "titkos-chat", storageBucket: "titkos-chat.firebasestorage.app", messagingSenderId: "477266640053", appId: "1:477266640053:web:f0328809e2875874de12fc" };

A Realtime Database szabályait állítsd így (Database → Rules):

{ "rules": { ".read": true, ".write": true } }
